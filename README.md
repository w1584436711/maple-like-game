# 浮島冒險記（Floating Isle）

瀏覽器就能玩的橫向捲軸動作小遊戲：在浮島村外的青草平原打怪、撿金幣、升等，深處還有一隻苔岩巨像。

角色、怪物、地圖都是用程式畫出來的，沒有使用任何外部圖片素材。操作手感參考經典橫向捲軸線上遊戲調整：走速 125、跳高約 77 px、爬繩 120、被擊中後 2 秒無敵。

## 怎麼玩

用瀏覽器打開 `index.html`，點一下畫面就能用鍵盤操作。手機也能玩，會出現觸控按鈕，建議橫放。

| 按鍵 | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ ↓ | 爬繩梯 |
| ↓ | 趴下 |
| Alt 或 Space | 跳躍 |
| ↓＋Alt | 從平台跳下 |
| Ctrl 或 X | 攻擊（按住連打） |
| Z | 撿東西 |
| Shift | 旋風斬（MP 8） |
| 1 / 2 | 紅／藍藥水 |

進度會自動存在這台裝置的瀏覽器裡。
