# 數值平衡（Lv.30～85）

這份文件記錄第 17 階段整理數值的方法和結果，之後調整數值時可以照著重算。

## 怎麼算

`tests/balance-sim.js` 會在遊戲頁面裡執行，直接用遊戲本身的升級公式、傷害公式（`rollDamage`）、技能表和裝備表來算，不另外抄一份公式。

每個職業、每個等級都配一個「一般玩家」的角色：

- **能力值**：都點主屬性；劍士和盜賊把敏捷保持在「等級 + 4」，維持命中。
- **裝備**：選等級夠、職業能穿的最高等級裝備，不算卷軸強化。熔心飾品要 Lv.80 以後才算進去。
- **技能點**：照轉職順序分配，每個階段賺到的點數只能點當時學得到的技能。先點這一轉的第一個攻擊技能，再點熟練度、爆擊、加傷害的被動技能，然後是其他攻擊技能。四轉技能書要 Lv.80 以後才算讀過。
- **輔助技能**：沒有冷卻時間的輔助技能都當作一直開著；四轉加傷害的輔助技能，照「持續時間 ÷ 冷卻時間」算有多少時間開著。
- **攻擊方式**：選每秒傷害最高、可以一直重複用的攻擊；大招有冷卻時間，用一次能多打多少傷害，就平均分到每一秒。
- **沒算到的事**：MP 和藥水、走路、躲招、怪物重生的時間。所以表裡的秒數是「站著不停攻擊」的時間，實際玩起來大約多 1～2 倍。

練功時假設一次會碰到 3 隻怪，範圍技能最多打到 3 隻；打 Boss 時只算 1 隻。熔心巨像的兩隻手臂會長兩次（第二次是 60% 血量），兩隻手臂站在一起，範圍技能可以一起打。

練功的怪選「等級不超過自己 + 2 的地圖怪物裡最強的」。Lv.71 以後都打聖甲蟲，因為還沒有更高等級的地圖（第 20 階段會加霜嶺）。

金幣算的是每隻怪平均掉的金幣，加上掉寶全部賣給商店的錢（裝備照商店價格的一半）。沒有扣掉藥水錢，也沒算任務獎勵和 Boss 掉寶。

## 重新產生表格

改了數值之後，執行下面這行，把印出來的表格貼到這份文件最後面：

```bash
node tools/balance.js
```

`npm test` 也會跑三項平衡測試，超出下面的目標就會失敗。

## 目標

| 項目 | 目標 |
| --- | --- |
| 每升一級要打幾隻怪 | 不超過 30 隻 |
| 一隻怪要打幾秒 | 每個職業都在 6 秒內 |
| 練功時職業差距（最慢 ÷ 最快） | 小於 2.5 倍 |
| 在建議等級打 Boss（不停攻擊） | 古樹精 Lv.35：15～60 秒；雷雲巨鷲 Lv.50：20～90 秒；沙暴蠍皇 Lv.75：20～120 秒；熔心巨像 Lv.80：60～300 秒（遠征限時 600 秒） |
| 打 Boss 時職業差距 | 小於 2.5 倍 |
| 金幣 | 越後面的怪越好賺（掉寶有運氣成分，不比前一種怪少 40% 以上就算過）；Lv.55～70 賺的錢夠買一把 Lv.55 武器、一套沙漠套裝和三件沙漠飾品 |

## 這次調整了什麼

調整前的問題：

- **職業差距太大**：同樣 Lv.75 打熔心巨像，劍士 43 秒、法師 179 秒，差 4 倍；Lv.70 打沙暴蠍皇，劍士 9 秒、法師 43 秒。三轉以後劍士練功也比其他職業快 2～4 倍。
- **Boss 太脆**：Lv.75 不停攻擊，沙暴蠍皇只要 8～19 秒就倒；Lv.50 打雷雲巨鷲只要 11～23 秒。
- **沙漠不好賺**：沙丘狐每隻平均只賺 873 金幣，比 Lv.46 的雷角犀（1,237）還少；練完 Lv.55～70 只賺到約 37 萬，但這段想買的裝備超過 100 萬。

改了這些：

| 項目 | 調整前 | 調整後 |
| --- | --- | --- |
| 法師：魔光彈 | 魔法攻擊 12 + 2×等級 | 16 + 2×等級 |
| 法師：火焰球 | 40 + 3×等級 | 50 + 4×等級 |
| 法師：雷鳴 | 32 + 2×等級 | 40 + 3×等級 |
| 法師：流星雨 | 60 + 3×等級 | 80 + 5×等級 |
| 法師：連鎖閃電 | 50 + 3×等級 | 90 + 5×等級 |
| 法師：星爆 | 55 + 3×等級 | 80 + 4×等級 |
| 法師：創世星爆 | 110 + 5×等級 | 150 + 6×等級 |
| 劍士：破天斬 | 砍三下 | 砍兩下 |
| 劍士：裂空斬 | 砍四下 | 砍三下 |
| 盜賊：千影手裏劍 | 只打第一隻怪 | 每支飛鏢穿過 2 隻怪 |
| 盜賊：拳爪攻擊 | 影牙 22、雲牙 30、沙蠍 36、聖甲 42 | 26、36、46、54 |
| Boss 血量 | 古樹精 22,000、雷雲巨鷲 60,000、沙暴蠍皇 200,000 | 40,000、160,000、700,000 |
| 熔心巨像血量 | 本體 900,000、手臂 150,000 | 本體 2,250,000、手臂 375,000 |
| 沙漠怪物的金幣 | 沙丘狐 180～300 … 聖甲蟲 280～460 | 全部變 3 倍 |
| 沙漠材料賣價 | 沙狐尾巴 220 … 聖甲蟲殼 420 | 全部變 2.5 倍 |

熔心巨像在 Lv.75 剛能進場時，法師不停攻擊也要 5 分多鐘，加上躲招很可能超過 10 分鐘的時限，所以 Lv.80 以下的玩家去找遠征隊長卡蘭時，卡蘭會建議 Lv.80 左右再來。

一般怪物的血量和經驗值沒有改：每級要打的怪數量從 Lv.30 的 10 隻慢慢增加到 Lv.84 的 26 隻，沒有突然變多或變少的地方。
