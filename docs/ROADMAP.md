# 開發藍圖

目標：讓系統和玩法盡量貼近經典楓之谷（舊版、約 v83 時期），但名稱、美術、音樂、地圖配置都自己原創。

## 原創界線（每個階段都要遵守）

- 可以照原版做：規則和數值機制，例如職業分支、轉職等級、能力值與傷害公式、每級 5 點 AP／3 點 SP、裝備部位與需求、卷軸成功率、商店買賣、任務流程、傳送門換地圖。
- 必須原創：地名、怪物名、NPC 名、道具名、技能名、劇情對話、角色與怪物外觀、地圖長相、音樂。職業的通用稱呼（劍士、法師、弓手、盜賊）可以用。
- 不從原版遊戲資料檔（.wz）取用任何東西。repo 是公開的，照抄會被要求下架。

## 階段

每個階段開一個分支、一個 PR。完成一段就 commit 並 push，PR 由使用者合併。

### 第 1 階段：能力值與職業（分支 `phase1-stats-jobs`）

- [x] 力量／敏捷／智力／幸運，每升一級 5 點 AP，能力值視窗（S 鍵）
- [x] 傷害依職業主屬性、副屬性和武器攻擊力計算，有最小～最大傷害、熟練度、命中率與 MISS
- [x] 每升一級 HP／MP 成長依職業不同
- [x] 村莊的轉職教官 NPC：Lv.10 一轉（法師 Lv.8），有能力值門檻，轉職後拿到 SP
- [x] 四個職業各有原創技能：主動攻擊技、增益技、被動技；技能視窗（K 鍵）用 SP 升級
- [x] 弓手射箭、盜賊丟飛鏢、法師放魔法彈（暫時不消耗彈藥，第 2 階段再加）
- [x] 舊存檔自動轉換，不會壞掉
- [x] 補自動測試：能力值加點、轉職、技能

### 第 2 階段：背包與裝備（分支 `phase2-inventory-equip`）

- [x] 分頁背包（裝備／消耗／其他），各 24 格，I 鍵打開；點一下看說明，點兩下穿上或使用，可以丟到地上
- [x] 裝備欄：帽子、上衣、褲子、鞋子、手套、披風、武器、盾牌，E 鍵打開；穿戴會畫在角色身上
- [x] 裝備有等級、職業、能力值需求，加成算進攻擊、魔力、防禦、能力值、HP／MP、命中、迴避；弓和拳爪是雙手武器
- [x] 每種怪物有自己的掉寶表（材料、藥水、彈藥、裝備），Boss 必掉 Lv.15 武器
- [x] 箭矢和飛鏢變成消耗品，飛鏢的攻擊力算進傷害；用完可以找轉職教官補（第 4 階段有商店後再改成用買的）
- [x] 舊存檔自動轉換：藥水搬進背包，補上職業武器和彈藥
- [x] 補自動測試：背包、穿脫裝備、需求不符、彈藥消耗、丟棄與撿回

### 第 3 階段：多張地圖與傳送門（分支 `phase3-maps`）

- [x] 浮島村（城鎮）加三張狩獵場：青草平原、刺殼海岸、苔岩遺跡；站在傳送門按 ↑ 換地圖，換圖時淡入
- [x] 每張地圖有自己的平台、繩梯、怪物、重生和風景（草原、海邊椰子樹、黃昏石柱遺跡）
- [x] 世界地圖（W 鍵）列出各地圖的怪物和等級，標出目前位置
- [x] 回村卷軸：在背包使用就回到浮島村；新角色送 2 張，怪物也會掉
- [x] 倒下後在浮島村復活；存檔記得最後所在的地圖
- [x] 補自動測試：傳送門換圖、世界地圖、回村卷軸

### 第 4 階段：NPC、商店、任務（分支 `phase4-npc-shop-quest`）

- [x] NPC 改成資料表：浮島村有轉職教官薇拉、道具商莫莉、武器商鐵叔、村長歐文，刺殼海岸有漁夫塔克；各自的外觀、對話，會轉身面向玩家
- [x] 商店買賣：道具商賣藥水、回村卷軸、箭矢、飛鏢；武器商賣武器和防具；什麼都能半價賣回，怪物材料有自己的收購價；賣裝備要按兩次確認
- [x] 箭矢、飛鏢改成跟道具商買（拿掉轉職教官免費補的做法）
- [x] 5 個任務，分「打倒幾隻」和「收集幾個」，有前置任務和等級門檻；NPC 頭上 ! 表示有新任務、? 表示可以回報；打怪、撿東西時顯示進度
- [x] 任務日誌（Q 鍵）：進行中、可以接、已完成
- [x] 補自動測試：買箭矢、賣裝備確認、接任務、回報打怪任務、回報收集任務

### 第 5 階段：進階內容（分支 `phase5-advanced`）

- [x] 二轉（Lv.30）：狂刃騎士、元素術士、獵鷹射手、影刃刺客，各有 3～4 個新技能（多段斬、範圍攻擊、雷擊、貫穿射擊、增益、熟練度）
- [x] 技能鍵從 3 個加到 5 個（預設 Shift、D、F、G、H），狀態列和觸控按鈕跟著加
- [x] 卷軸強化：裝備有可升級次數；武器、防具、手套卷軸 60% 和 10%，成功加能力，失敗只扣次數；強化過的裝備存檔、丟下再撿都保留
- [x] 三張新地圖：潮汐礁岩（Boss 巨鉗蟹王 Lv.22）、霧影森林（霧菇 Lv.18、石甲蜥 Lv.25，有霧）、古樹深處（Boss 霧林古樹精 Lv.32）
- [x] Boss 改成通用設定：每隻有自己的蓄力時間、冷卻、範圍和傷害
- [x] 新裝備：Lv.25 四職業武器、霧林兜帽、甲蜥鎧甲和護腿、蟹殼盾、古樹披風
- [x] 鍵位設定（O 鍵）：每個動作都能改鍵，存在瀏覽器；按鍵說明、狀態列、對話裡的按鍵名稱都跟著變
- [x] 補自動測試：二轉、二轉技能、卷軸成功與失敗、改鍵位、新地圖

### 平衡調整（分支 `balance-15-30`）

- [x] Lv.15→30 從約 416 隻怪降到約 191 隻：刺殼龜、霧菇、石甲蜥經驗值調高，霧菇和石甲蜥血量調低
- [x] 兩隻新 Boss 調弱：血量約減四成，重擊傷害降低、蓄力和冷卻變長，經驗值調高
- [x] 補自動測試：Lv.15→30 打怪數量不能超過 250 隻

## 第二版（規劃中，順序可以再調）

第一版的五個階段都完成了。第二版先把 Lv.1～30 玩順，再往新大陸和三轉走；每個階段一樣開一個分支、一個 PR。

### 第 6 階段：練功節奏與任務（分支 `phase6-quests`）

- [x] 三個新 NPC：潮汐礁岩的潛水員瑪琳、霧影森林的採菇人波波、古樹深處的守林人艾德
- [x] Lv.15～30 七個任務，串成三條任務鏈：礁岩的霸主 → 蟹鉗做的工具；霧菇大豐收 → 孢子的祕密 → 石甲蜥出沒；守林人的盔甲 → 沉睡吧，古樹精
- [x] 四個每日任務（村長、漁夫、採菇人、守林人各一個），做完當天不能再接，隔天重新開放；任務日誌另外列出今天做完的每日任務
- [x] 倒下損失的經驗值：新手不扣；一轉後從 10% 開始，每升一級少 0.25%，最低 3%
- [x] 補自動測試：任務鏈、每日任務隔天重置、倒下損失

### 第 7 階段：裝備養成（分支 `phase7-gear`）

- [x] 怪物掉的裝備，每項能力在原本數值上下約一成（至少 ±1）浮動；說明裡綠字是好運、紅字是壞運，強化加成是金字
- [x] 兩套套裝：冒險者套裝（皮革便帽、果凍紋上衣、帆布長褲、疾風短靴）、霧林套裝（霧林兜帽、甲蜥鎧甲、甲蜥護腿、古樹披風），穿越多件加成越多
- [x] 倉庫管理員蘿絲（浮島村）：24 格倉庫，裝備連同強化和浮動一起存，消耗品和材料可以疊
- [x] 道具商新賣兩種卷軸：防爆卷軸（下一次強化失敗不扣次數）、回復卷軸（50% 補回一次失敗用掉的次數）
- [x] 補自動測試：能力浮動範圍、套裝加成、倉庫存取、防爆和回復卷軸

### 第 8 階段：新大陸「雲頂城」（Lv.30～50）（分支 `phase8-cloud`）

- [x] 飛船船長葛雷：浮島村和雲頂城之間來回，每趟船票 1000 金幣
- [x] 雲頂城：雲商妮娜（白藥水、魔力藥水、卷軸、雲絲裝備、Lv.40 武器）、雲守衛雷恩（五個任務的任務鏈和一個每日任務）
- [x] 三張狩獵場：雲海步道（棉雲羊 Lv.32）、風之高台（風鈴精 Lv.40、雷角犀 Lv.46）、雷雲祭壇（Boss 雷雲巨鷲 Lv.50，會打雷閃光）
- [x] 新裝備：四職業 Lv.40 武器、雲絲套裝（帽子、長袍、長褲、靴子）、雲紋盾、雷羽披風
- [x] 回村卷軸和倒下復活會回到所在大陸的城鎮；藥水鍵會先喝白藥水、魔力藥水
- [x] 世界地圖分成浮島和雲頂兩區
- [x] 補自動測試：搭船來回、雲頂的回村卷軸、藥水鍵、雲頂任務和世界地圖

### 第 9 階段：三轉（Lv.50）（分支 `phase9-third-job`）

- [x] 雲頂城的賢者奧菈：二轉後到 Lv.50 給「影之試煉」，接下就進試煉場，打倒拿著你武器的影子分身（Lv.55），回報後三轉
- [x] 四個三轉職業：破陣劍豪、星辰賢者、神射遊俠、夜影宗師，各 4 個新技能（多段範圍攻擊、流星雨、箭雨、連鎖閃電、貫穿 6 隻的狙擊、不耗 MP、暴擊加成）
- [x] 技能鍵增加到 7 個（預設 Shift、D、F、G、H、V、B）；技能視窗每個主動技能都能選放在哪個鍵，存檔會記住
- [x] 補自動測試：三轉流程、還沒二轉接不到試煉、把技能放到第 7 個鍵

### 第 10 階段：聲音與設定

- 用程式產生的原創音效（揮砍、命中、升級、撿錢）和背景音樂，不用外部檔案
- 設定視窗：音量、要不要顯示傷害數字、畫面震動強度
- 多個存檔欄位，存檔可以匯出成文字、在別台裝置匯入
- 測試：設定會保存、存檔匯出再匯入後角色一樣

## 在雲端接手

1. 在 claude.ai/code 開新對話，選 repo `w1584436711/maple-like-game`。
2. 說「照 docs/ROADMAP.md 繼續目前的階段」。開機時會自動 `npm install`。
3. 先 `git fetch` 並切到該階段的分支，從還沒打勾的項目接著做；改完照 CLAUDE.md 跑 `npm test` 再 commit、push。
4. 想在手機試玩還沒合併的版本，可以請 Claude 把分支上的 `index.html` 發佈成 claude.ai 網頁預覽。
