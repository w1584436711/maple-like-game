# 浮島冒險記（Floating Isle）

瀏覽器就能玩的橫向捲軸動作小遊戲：從浮島村出發，穿過傳送門到青草平原、刺殼海岸打怪、撿裝備、升等，Lv.10 回村找轉職教官選擇劍士、法師、弓手或盜賊，苔岩遺跡深處還有一隻苔岩巨像。

系統和玩法參考經典楓之谷（能力值、轉職、技能點、分頁背包、裝備欄），名稱、外觀和數值細節都是原創。開發順序見 [docs/ROADMAP.md](docs/ROADMAP.md)。

角色、怪物、地圖都是用程式畫出來的，沒有使用任何外部圖片素材。操作手感參考經典橫向捲軸線上遊戲調整：走速 125、跳高約 77 px、爬繩 120、被擊中後 2 秒無敵。

## 怎麼玩

用瀏覽器打開 `index.html`，點一下畫面就能用鍵盤操作。手機也能玩，會出現觸控按鈕，建議橫放。

## 寵物

浮島村的寵物飼育員露露賣三種寵物：毛球兔、圓圓雞、甜甜狸，每隻 3000 金幣，買了會送 5 個寵物飼料。

- 寵物會跟在角色後面，會跳上平台，離太遠會直接出現在你身邊。
- 會自動撿起角色附近的金幣和道具。只想讓牠撿金幣的話，可以在設定（P）把「寵物也撿道具」關掉。
- 每 30 秒飽足度少 1。低於 20 就會肚子餓，不幫你撿東西。在背包對寵物飼料點兩下，飽足度加 30（道具商、雲商和露露都有賣）。
- 親密度：餓的時候餵食加 3，吃飽的狀態下每陪你 2 分鐘加 1。親密度等級越高，撿東西的範圍越大；Lv.2 會跟你說話，Lv.3 會翻跟斗。
- 可以買好幾隻，找露露換別隻出來，或讓牠回去休息。

## 遠征：熔心祭壇（Lv.75）

- 沉砂城的遠征隊長卡蘭：做完守衛隊長哈山的任務鏈後，接「熔岩的低語」（30 個聖甲蟲殼換 3 張熔心入場證），之後每天可以做「遠征準備」（15 個聖甲蟲殼換 2 張）。
- 每次進場交一張入場證，每天最多挑戰 2 次，限時 10 分鐘。時間到或在裡面倒下都算失敗，會用掉一次，但不扣經驗值。
- Boss 熔心巨像 Lv.85 分成本體和兩隻熔岩巨臂：手臂都打斷之前，本體有護盾打不到。
- 三個階段：
  - 第一階段：先打手臂。
  - 第二階段（本體剩 2/3）：手臂重新長出來，天上開始掉熔岩，熔岩淹地前會有全畫面警告，要跳到平台上躲。
  - 第三階段（剩 1/3）：熔岩掉得更密，還會輪流放熔岩淹地和要跳起來躲的衝擊波。
- 打倒後一定掉一件熔心飾品（耳環、項鍊或戒指），還有飾品全能卷軸 10%、武器卷軸 10%、防爆卷軸等。

## 背包與裝備

- 怪物各有掉寶表：材料、藥水、箭矢、飛鏢，偶爾掉裝備；苔岩巨像一定會掉一把 Lv.15 武器。
- 裝備有等級、能力值和職業需求，不符合的格子會變紅，說明裡紅字的就是還差的條件。
- 裝備的攻擊、魔力、防禦、能力值、HP／MP、命中、迴避都會算進角色。能力值視窗會在原本的數值旁邊顯示（+加成）。
- 弓和拳爪是雙手武器，拿著時不能用盾牌。
- 飾品欄：耳環、項鍊、戒指。沙商莎雅賣 Lv.60 的沙金耳環、沙紋項鍊、沙之戒指；熔心祭壇掉 Lv.75 的熔心耳環、熔心項鍊、熔心戒指。飾品可以用飾品全能卷軸強化。
- 穿戴的帽子、衣服、褲子、鞋子、手套、披風、盾牌會直接畫在角色身上。
- 在背包點兩下可以穿上裝備或喝藥水；不要的東西可以丟到地上，按 Z 撿回來。
- 卷軸強化：每件裝備有可升級次數（武器 7 次、其他 5 次）。在背包的消耗欄使用卷軸，再選要強化的裝備；60% 卷軸加得少、10% 卷軸加得多，不管成不成功都會用掉一次。強化過的裝備名稱後面會顯示 +幾。
- 防爆卷軸：先貼在裝備上，下一次強化失敗就不會扣次數。回復卷軸：50% 機率補回一次失敗用掉的次數。兩種都跟道具商莫莉買。
- 怪物掉的裝備能力會在原本數值上下約一成浮動，說明裡綠字是比較好、紅字是比較差；商店買的和任務給的是標準值。
- 套裝：冒險者套裝（皮革便帽、果凍紋上衣、帆布長褲、疾風短靴）、霧林套裝（霧林兜帽、甲蜥鎧甲、甲蜥護腿、古樹披風）、雲絲套裝、沙漠套裝（沙漠頭巾、沙漠長衫、沙漠燈籠褲、沙行靴）和古墓套裝（古墓頭冠、陶俑胸甲、陶俑護腿、王陵披風），穿越多件加成越多，裝備視窗會顯示目前件數。
- 沙漠的武器：Lv.55 的流砂彎刀、烈陽法杖、沙丘長弓、沙蠍拳爪在沙商買；Lv.65 的墓王巨劍、冥月法杖、金沙王弓、聖甲拳爪要打墓守陶俑、聖甲蟲或沙暴蠍皇。

## 檔案

不需要安裝或建置，直接打開 `index.html` 就能玩。

| 檔案 | 放什麼 | 想改這些時打開它 |
| --- | --- | --- |
| `index.html` | 畫面結構：遊戲畫面、各個視窗、按鍵說明、觸控按鈕 | 加一個新視窗或按鈕 |
| `css/style.css` | 外觀樣式 | 視窗、按鈕的顏色和排版 |
| `js/core.js` | 畫面大小、移動手感的數值、共用小工具 | 走速、跳躍高度 |
| `js/audio.js` | 音效、背景音樂、設定（音量、傷害數字、震動） | 音效的聲音、音樂的調性和速度 |
| `js/world.js` | 地圖、怪物、傳送門 | 新地圖、新怪物、怪物血量和掉寶 |
| `js/rules.js` | 職業、技能、傷害公式、道具、價格 | 新道具或裝備、技能數值、商店價格 |
| `js/player.js` | 角色資料、按鍵、存檔 | 新按鍵、存檔格式 |
| `js/raid.js` | 遠征：入場、每日次數、時間限制、熔心巨像的手臂、階段和全畫面大招 | 次數、時限、各階段的攻擊頻率和傷害 |
| `js/pet.js` | 寵物種類、跟隨、自動撿東西、飢餓和親密度 | 新寵物、寵物的價格和台詞、撿東西範圍 |
| `js/npc.js` | NPC、對話、任務、商店清單、轉職 | 新 NPC、新任務、商店賣什麼 |
| `js/ui.js` | 能力值、技能、背包、裝備、商店、任務、世界地圖視窗 | 視窗裡顯示的內容 |
| `js/combat.js` | 戰鬥、掉落、升級、每一格畫面的更新 | 戰鬥規則 |
| `js/draw.js` | 畫面上看到的一切：風景、NPC、怪物、道具、角色、狀態列 | 外觀和動畫 |
| `js/main.js` | 遊戲迴圈和開始遊戲 | 很少需要改 |

`js/` 裡的檔案按照 `index.html` 列的順序載入，彼此共用名稱。

- `tests/smoke.spec.js`：自動試玩測試
- `docs/ROADMAP.md`：開發藍圖和原創界線

## 自動試玩測試

每次修改後，可以用瀏覽器自動試玩一遍，確認遊戲沒壞：

```bash
npm install
npx playwright install chromium   # 第一次才需要
npm test
```

會檢查這些事：

1. 遊戲畫面正常顯示，沒有程式錯誤
2. 按住右鍵角色會往右走（看小地圖上的黃點），跳躍、攻擊不出錯
3. 離開頁面時會把進度存進瀏覽器
4. 舊存檔會補回能力值，能在能力值視窗加點
5. Lv.10 找轉職教官轉成劍士，學技能並施放
6. 能力值不夠時，轉職教官會說還差多少
7. 盜賊丟飛鏢、放技能都不出錯
8. 舊存檔的藥水搬進背包，在消耗欄喝藥水
9. 穿上、卸下裝備，等級不夠就穿不上
10. 弓手射箭會用掉箭矢，用完可以跟道具商買
11. 賣裝備要按兩次確認
12. 找村長接任務，任務日誌顯示進度
13. 打倒的數量夠了，回村長那裡拿獎勵
14. 收集任務會收走材料、給裝備
15. 轉職成盜賊會拿到拳爪和飛鏢
16. 丟掉的東西會掉在地上，按 Z 可以撿回來
17. 站在傳送門按 ↑ 會換地圖，世界地圖標出所在位置
18. 讀回村卷軸會回到浮島村
19. Lv.30 找轉職教官二轉，學到新技能
20. 狂刃騎士按技能 4 的鍵放出斷岩斬
21. 元素術士放火焰球、冰霜新星、雷鳴都不出錯
22. 卷軸強化：成功會加攻擊，失敗只扣可升級次數
23. 鍵位設定：把攻擊改到 J，重新整理後還在
24. 世界地圖列出新的三張地圖
25. 練功速度：Lv.15 練到 Lv.30 不用打超過 250 隻怪
26. 任務鏈：回報霧菇大豐收之後，採菇人會給下一個任務
27. 每日任務：今天做完就不能再接，隔天又可以接
28. 倒下損失的經驗值隨等級變少，新手不會損失
29. 怪物掉的裝備能力會小幅浮動，不會超過一成
30. 套裝：穿上霧林套裝 3 件，多出 2 件和 3 件的加成
31. 倉庫：存進去的東西重新整理後還在，也拿得回來
32. 防爆卷軸擋住一次失敗，回復卷軸補回失敗的次數
33. 搭飛船往返浮島村和雲頂城，每趟付 1000 金幣
34. 在雲頂的狩獵場讀回村卷軸，會回到雲頂城
35. 紅藥水鍵會先喝白藥水
36. 雲守衛給任務，世界地圖分成浮島、雲頂和沉砂
37. 三轉：接影之試煉會進試煉場，打倒影子後回報就能三轉
38. 還沒二轉的 Lv.50 角色接不到影之試煉
39. 技能視窗可以把技能放到第 7 個鍵，按 B 就放得出來
40. 設定：音量、傷害數字、畫面震動，重新整理後還在
41. 存檔欄位：切到空的存檔 2 是新角色，切回存檔 1 還是原本的角色
42. 匯出存檔再匯入到另一個欄位，角色一模一樣
43. 點一下畫面就會開始有聲音，在文字框打字不會觸發遊戲按鍵
44. 跟寵物飼育員買寵物，寵物會跟出來，還送 5 個飼料
45. 寵物會自動撿附近的金幣，肚子餓了就不撿
46. 在背包對寵物飼料點兩下會餵寵物，餓的時候餵親密度會上升
47. 按 M 切換小地圖：小、大、關閉，重新整理後還記得
48. 從雲頂城搭飛船到沉砂城，狩獵場的回村卷軸回到沉砂城，世界地圖多了沉砂
49. 鑽沙蚯躲在沙裡時打不到，會鑽到腳下冒出來咬人
50. 仙人掌怪會從遠處丟刺過來
51. 沙暴蠍皇會召喚小沙蠍，血量剩一半會發怒，打倒後小沙蠍也一起消失
52. 地下古墓很暗，只有角色附近看得清楚
53. 四轉：交兩件信物、打倒真影分身，就能成為裂空劍帝，二轉技能還在
54. 天劍審判有 60 秒冷卻：冷卻中再按不會放，狀態列看得到
55. 四轉技能先到 Lv.20，讀了技能書才能升到 Lv.30；別的職業的書看不懂
56. 遠征：交入場證才能進，每天 2 次；時間到或倒下都不扣經驗
57. 熔心巨像：兩隻手臂都打斷前，本體打不到
58. 熔心巨像換階段：手臂長回來；熔岩淹地前有警告，站在地上會受傷、平台上不會
59. 耳環、項鍊、戒指三個新欄位；在熔心祭壇存檔會回到沉砂城
60. 手機上會出現觸控按鈕，按了不會出錯

開 PR 或推到 `main` 時，GitHub Actions 也會自動跑這些測試。Claude Code 雲端對話開機時會自動裝好測試工具（`.claude/hooks/session-start.sh`）。
