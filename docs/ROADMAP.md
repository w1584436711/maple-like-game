# 開發藍圖

目標：讓系統和玩法盡量貼近經典楓之谷（舊版、約 v83 時期），但名稱、美術、音樂、地圖配置都自己原創。

## 原創界線（每個階段都要遵守）

- 可以照原版做：規則和數值機制，例如職業分支、轉職等級、能力值與傷害公式、每級 5 點 AP／3 點 SP、裝備部位與需求、卷軸成功率、商店買賣、任務流程、傳送門換地圖。
- 必須原創：地名、怪物名、NPC 名、道具名、技能名、劇情對話、角色與怪物外觀、地圖長相、音樂。職業的通用稱呼（劍士、法師、弓手、盜賊）可以用。
- 不從原版遊戲資料檔（.wz）取用任何東西。repo 是公開的，照抄會被要求下架。

## 階段

每個階段開一個分支、一個 PR。完成一段就 commit 並 push，PR 由使用者合併。

## 第三版（規劃中，順序可以再調）

第二版的內容到 Lv.55 左右。第三版先補上楓之谷經典的陪伴和便利功能，再往 Lv.55～80 推：新大陸、四轉、需要準備才打得過的大型 Boss，最後加上收集要素讓角色練滿之後還有事做。每個階段一樣開一個分支、一個 PR。

原版四轉在 Lv.120，這裡的等級曲線比較短，四轉提前到 Lv.70，其他規則（四轉技能上限、需要前置任務和信物）照原版的感覺做。

- [x] 怪物圖鑑（J 鍵）：每種怪物（召喚出來的和試煉的影子除外）偶爾掉卡片，Boss 比較常掉；卡片直接收進圖鑑不佔背包，集滿 5 張點亮一頁，每點亮 4 頁全能力值 +1
- [x] 跳跳挑戰：浮島村的教練小飛帶你去「彩虹跳台」，雲頂城的教練小雲帶你去「雲階試煉」；掉到地上從頭開始，到終點第一次送椅子，之後每天一次獎勵
- [x] 稱號：轉職、Lv.50、打倒每隻 Boss、圖鑑點亮數量、跳跳挑戰、寵物親密度等 16 個；一次戴一個，顯示在角色腳下，有些戴上時有小加成
- [x] 椅子：木頭小板凳、棉雲沙發、沙丘躺椅；在背包點兩下坐下，回復變成三倍再加椅子的回復量，一動就站起來
- [x] 補自動測試：卡片點亮圖鑑和加成、跳跳挑戰的掉落重來與每日獎勵、解鎖和戴上稱號、坐椅子回復

第三版的五個階段都完成了。

## 第四版（規劃中，順序可以再調）

前三版把等級推到 Lv.85，系統也大致齊全，但 Lv.30 以後的數值大多是推算的，角色也還沒有名字和外觀。第四版先讓角色有自己的樣子、把數值整理一遍，再補上楓之谷常見的製作、組隊任務和坐騎，最後開一塊 Lv.85～100 的新大陸。每個階段一樣開一個分支、一個 PR。

### 第 16 階段：角色建立與外觀（分支 `phase16-character`）

- [x] 新角色（包括重新開始和切到空的存檔欄位）先進入建立畫面：取名字（2～12 個字）、選 5 種髮型、8 種髮色、4 種膚色、5 種眼睛顏色，左邊是用遊戲本身畫法畫的預覽，也可以按「隨機」；建立畫面開著時遊戲按鍵沒有作用
- [x] 名字顯示在角色腳下的名牌上，戴稱號時稱號在名字上面；設定視窗的存檔欄位和匯出的存檔都有名字
- [x] 浮島村的美髮師卡莉（髮型 3000、髮色 2000 金幣）、雲頂城的整形師米卡（眼睛顏色 5000 金幣），沒改或金幣不夠會提醒
- [x] 舊存檔沒有外觀資料：第一次讀取時跳出建立畫面補上名字和外觀，等級、背包都不變
- [x] 補自動測試：建立角色和名字檢查、隨機外觀、舊存檔補名字、美髮店付費換髮型；其他測試用「測試員」自動建立角色

### 第 17 階段：Lv.30～85 平衡整理（分支 `balance-30-85`）

- [x] 用程式模擬每一級要打幾隻怪（`tests/balance-sim.js`，直接用遊戲本身的公式）：Lv.30 的 10 隻慢慢增加到 Lv.84 的 26 隻，沒有突然變多或變少的區段，一般怪物的血量和經驗值不用改
- [x] 模擬四個職業、各種等級打每隻 Boss 和熔心巨像要花多久：法師和盜賊加強、劍士的破天斬和裂空斬少砍一下，職業差距從最多 4 倍縮到 2.5 倍以內；Boss 血量加厚（沙暴蠍皇 20 萬 → 70 萬，熔心巨像本體 90 萬 → 225 萬）
- [x] 檢查金幣：沙漠怪物比雷角犀還難賺，沙漠怪物的金幣變 3 倍、材料賣價變 2.5 倍，Lv.55～70 從約 37 萬變成約 55 萬，夠買一輪沙漠裝備
- [x] 調整前後和模擬結果寫成表格放進 `docs/BALANCE.md`，`node tools/balance.js` 可以重新產生
- [x] 補自動測試：Lv.30～85 每級的打怪數量和打怪秒數、四隻 Boss 在建議等級的擊殺時間、職業差距、金幣都在設定的範圍內

### 第 18 階段：製作系統（分支 `phase18-crafting`）

- 浮島村、雲頂城、沉砂城各一位工匠 NPC，用怪物材料加金幣製作東西：藥水、卷軸、裝備、飾品
- 製作視窗：列出配方、需要的材料和數量（背包有多少），按一下就製作，有成功率的配方會顯示機率
- 製作熟練度：做越多東西等級越高，高等級才能做更好的配方
- 怪物材料從「只能賣錢」變成有用的東西；有些稀有配方要靠 Boss 掉的配方書才學得到
- 補自動測試：材料足夠才能做、製作後材料扣掉、熟練度升級、配方書解鎖

### 第 19 階段：傭兵隊友與組隊任務（分支 `phase19-party-quest`）

- 傭兵：在城鎮雇用一位 AI 隊友（劍士、法師、弓手或盜賊），跟著你走、自己打怪、會補血；雇用要付金幣，有時間限制
- 組隊任務「失落的鐘塔」（Lv.35～50）：一次進場、好幾個關卡，每關有不同的機關，例如照順序踩踏板、收集通行證、在時間內打倒指定的怪，最後打 Boss
- 每天可以挑戰幾次，通關拿經驗值和專屬獎勵（組隊任務限定的帽子或椅子）
- 補自動測試：雇用和解雇傭兵、傭兵會攻擊、組隊任務各關的過關條件、通關獎勵

### 第 20 階段：新大陸「霜嶺」與坐騎（分支 `phase20-frost`）

- 新大陸「霜嶺」（Lv.85～100）：城鎮和四張狩獵場，冰面會滑、暴風雪會降低視線，新怪物包括會冰凍玩家（短時間不能動）的怪
- Boss 冰晶龍（Lv.100）：會飛到空中、吐冰息，地上會冒出冰柱
- 坐騎：Lv.70 以後可以學騎乘技能，騎上坐騎移動和跳躍變快，被打到會掉下來
- 新裝備：Lv.85、Lv.95 四職業武器、霜嶺套裝；四轉技能書也會從冰晶龍掉
- 補自動測試：前往霜嶺、冰面滑行、冰凍狀態、坐騎加速、冰晶龍的招式
