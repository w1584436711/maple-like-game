# 浮島冒險記（Floating Isle）

瀏覽器就能玩的橫向捲軸動作小遊戲：在浮島村外的青草平原打怪、撿金幣、升等，Lv.10 找轉職教官選擇劍士、法師、弓手或盜賊，深處還有一隻苔岩巨像。

系統和玩法參考經典楓之谷（能力值、轉職、技能點），名稱、外觀和數值細節都是原創。開發順序見 [docs/ROADMAP.md](docs/ROADMAP.md)。

角色、怪物、地圖都是用程式畫出來的，沒有使用任何外部圖片素材。操作手感參考經典橫向捲軸線上遊戲調整：走速 125、跳高約 77 px、爬繩 120、被擊中後 2 秒無敵。

## 怎麼玩

用瀏覽器打開 `index.html`，點一下畫面就能用鍵盤操作。手機也能玩，會出現觸控按鈕，建議橫放。

| 按鍵 | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ ↓ | 爬繩梯 |
| ↓ | 趴下 |
| Alt 或 Space | 跳躍 |
| ↓＋Alt | 從平台跳下 |
| Ctrl 或 X | 攻擊（按住連打） |
| Z | 撿東西 |
| Shift、D、F | 技能（轉職後學） |
| 1 / 2 | 紅／藍藥水 |
| S | 能力值視窗（升級拿到的 AP 在這裡分配） |
| K | 技能視窗（轉職後用 SP 學技能） |
| 靠近 NPC 按 Space，或點 NPC | 對話 |

進度會自動存在這台裝置的瀏覽器裡。

## 職業

| 職業 | 轉職條件 | 主屬性 | 攻擊方式 |
| --- | --- | --- | --- |
| 劍士 | Lv.10、力量 35 | 力量 | 近身揮劍 |
| 法師 | Lv.8、智力 20 | 智力 | 魔法彈 |
| 弓手 | Lv.10、敏捷 25 | 敏捷 | 射箭 |
| 盜賊 | Lv.10、敏捷 25 | 幸運 | 丟飛鏢 |

每升一級拿到 5 點能力值（AP）；轉職後每級再拿 3 點技能點（SP）。

## 檔案

- `index.html`：整個遊戲（HTML、CSS、JavaScript 都在這一個檔案裡）
- `tests/smoke.spec.js`：自動試玩測試
- `docs/ROADMAP.md`：開發藍圖和原創界線

## 自動試玩測試

每次修改後，可以用瀏覽器自動試玩一遍，確認遊戲沒壞：

```bash
npm install
npx playwright install chromium   # 第一次才需要
npm test
```

會檢查這些事：

1. 遊戲畫面正常顯示，沒有程式錯誤
2. 按住右鍵角色會往右走（看小地圖上的黃點），跳躍、攻擊不出錯
3. 離開頁面時會把進度存進瀏覽器
4. 舊存檔會補回能力值，能在能力值視窗加點
5. Lv.10 找轉職教官轉成劍士，學技能並施放
6. 能力值不夠時，轉職教官會說還差多少
7. 盜賊丟飛鏢、放技能都不出錯
8. 手機上會出現觸控按鈕，按了不會出錯

開 PR 或推到 `main` 時，GitHub Actions 也會自動跑這些測試。Claude Code 雲端對話開機時會自動裝好測試工具（`.claude/hooks/session-start.sh`）。
